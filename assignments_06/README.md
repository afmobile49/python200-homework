# Assignment 06 - RAG with LlamaIndex

Code the Dream - Python 200

## Files

- warmup_06.py: RAG concepts, keyword retrieval, semantic retrieval, and LlamaIndex evaluation.
- project_06.py: Groundwork Coffee Q&A assistant.

## Setup

Install dependencies:

pip install openai pypdf python-dotenv "llama-index-core==0.14.10" llama-index-embeddings-openai llama-index-llms-openai llama-index-readers-file

Create a .env file at the repository root containing OPENAI_API_KEY.

Copy the official lesson resources into:

- assignments_06/resources/brightleaf_pdfs/
- assignments_06/resources/groundwork_docs/

Original resources:
https://github.com/Code-the-Dream-School/python-200-v1/tree/main/lessons/06_AI_augmentation/resources

## Run

python assignments_06/warmup_06.py
python assignments_06/project_06.py

Both scripts use the OpenAI API and may incur charges.
